# My Dream Coding Project: EcoTrack 

## Project Overview

**EcoTrack** is an app designed to help user *track their daily carbon footprint* and make small, sustainable choice that add up to a big impact. It's built using **HTML**, **CSS** and **JavaScript** - but one day, I want to expand it into a full web platform! 

---

## Project Goals

- Build a user-freindly dashboard that tracks: 
  - *Energy use*
  - *Transportation impact*
  - *Food consumption patterns*
- Display personalized reports using: 
  - `console.log()` to debug progress
  
  ```js
  if (carbonScore < 50) { console.log("Great job satying sco-friendly!");} else {console.log("Lets find wasys to reduce your footprint);}
  ```
